# photomate.cc

Archived showcase of PhotoMate, the AI photo editing and scoring service (closed). Static page on
GitHub Pages: `index.html`, `style.css`, `app.js` (before/after sliders, FR/EN switch), images in
`img/` (Pexels sample photos, original and PhotoMate edit, resized to 1600 px).

No build step, no external request. Preview: `python3 -m http.server 8797`.

The former WordPress site (OVH hosting `photobb`) was backed up on 2026-10-22 before being cleaned:
database dump and all files in `/volume1/Documents/Archives/photomate/photomate-wordpress-2026-10-22.tar.gz`
on the NAS (see the `nas-bulb` skill for access). The hosting now only serves a one-line page
pointing here; its FTP/SFTP password is in Bitwarden (`OVH__PHOTOMATE_FTP_PASSWORD`).
